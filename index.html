About

I'm Marc Daryll Trinidad, known as Charlie Soniac Spencer — a BSIT graduate from St. Paul University of Surigao. Full-stack developer by practice, debater by challenge, and athlete by discipline.

I code the way I lift — sometimes ugly, always intentional. I'm a vibe coder who uses AI tools to move fast, but I always make sure I understand the problems I'm actually solving. The ideas in my head run faster than my legs ever will — and I'm okay with that.

I'm paradoxical. I stay in rooms that don't always want me, because I know how to grow in uncomfortable soil. I get sad. I wake up neutral. I get back to work. That cycle is the only cheat code I know.

Charlie

A production-ready municipal chatbot and document tracker developed as my OJT project at the Surigao City Hall MIS Division to complete my 500-hour requirement. Charlie is an offline assistant combining a hybrid RAG (ChromaDB/BM25) pipeline with a Redis cache for instant document tracking. I designed the backend, prompt guardrails, and configured a headless Ubuntu server on a Windows PC to run a local Ollama Llama 3.1 model. Partnered with Jade Mancio (NEMCO), who helped implement message sharing, printing, and UI enhancements.

Django 6.0 Python FastAPI ChromaDB Ollama / Llama 3.1 Redis BM25 Okapi Streaming SSE
Dual-Node Offline Architecture linking client laptop to local headless server
Hybrid Search blending semantic vector retrieval (ChromaDB) and lexical keyword matching (BM25) via RRF
Instant Document Status & Routing Tracker leveraging high-performance Redis indexes
Smart Chunking & Text Extraction pipelines for PDF, DOCX, and TXT references
Dynamic Conversation Sharing with a custom modal link generator
Interactive Chat Interface supporting markdown, message editing, and SSE stream locking
